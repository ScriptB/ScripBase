# Admin Scripts

This directory contains server administration and moderation scripts.

## Guidelines

- Use clear, action-based names: `kick-player.lua`, `ban-user.lua`, `server-stats.lua`
- Include permission checks in scripts
- Document required admin level/permissions
- Add safety checks to prevent misuse

## Examples

- Player management (kick, ban, warn)
- Server monitoring and statistics
- Moderation tools
- Server configuration scripts

## Usage

Admin scripts typically require elevated permissions. Include permission requirements in script headers.
