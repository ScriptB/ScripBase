# Game-Specific Scripts

This directory contains scripts specific to particular Roblox games.

## Organization

Create a subdirectory for each game:
```
games/
├── arsenal/
│   ├── esp.lua
│   └── aimbot.lua
├── jailbreak/
│   ├── auto-rob.lua
│   └── vehicle-speed.lua
└── adopt-me/
    └── auto-feed.lua
```

## Guidelines

- Use game name as subdirectory (lowercase with hyphens)
- Keep game-specific scripts in their respective folders
- Include game version compatibility in comments if relevant
- Document game-specific requirements

## Naming Convention

Use descriptive names that indicate the script's purpose within the game context.
