# GUI Scripts

This directory contains user interface scripts and menu systems.

## Guidelines

- Name based on interface purpose: `main-menu.lua`, `settings-panel.lua`, `hud.lua`
- Keep UI logic separate from functionality
- Document UI elements and controls
- Include screenshots or descriptions of the interface

## Examples

- Main menu systems
- Settings panels
- HUD overlays
- Notification systems
- Custom UI libraries

## Usage

GUI scripts should be modular and easy to integrate with other scripts.
