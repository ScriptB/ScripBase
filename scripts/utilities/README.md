# Utility Scripts

This directory contains helper functions, libraries, and reusable tools.

## Guidelines

- Keep utilities generic and reusable
- Document function parameters and return values
- Name based on functionality: `http-lib.lua`, `string-utils.lua`, `math-helpers.lua`
- Make utilities modular for easy integration

## Examples

- HTTP request libraries
- String manipulation functions
- Math and calculation helpers
- Animation utilities
- Data structure implementations

## Usage

Utilities should be designed to be imported/required by other scripts.
