# ScripBase
All My Scripts For Roblox

## 📁 Repository Structure

This repository is organized to keep all Roblox scripts well-organized with good naming conventions and easy management.

```
ScripBase/
├── scripts/           # Main scripts directory
│   ├── exploits/     # Exploit scripts
│   ├── utilities/    # Utility and helper scripts
│   ├── games/        # Game-specific scripts
│   ├── admin/        # Admin and moderation scripts
│   └── gui/          # GUI and interface scripts
├── examples/         # Example scripts for learning
├── templates/        # Script templates to start new scripts
└── docs/            # Additional documentation
```

## 🚀 Getting Started

1. Browse the `scripts/` directory to find the type of script you need
2. Use the template in `templates/script-template.lua` when creating new scripts
3. Follow the naming conventions in `CONTRIBUTING.md`

## 📝 Script Categories

### Exploits (`scripts/exploits/`)
Scripts that modify game behavior or provide advantages.

### Utilities (`scripts/utilities/`)
Helper functions, libraries, and reusable tools.

### Games (`scripts/games/`)
Scripts specific to particular Roblox games. Organized by game name in subdirectories.

### Admin (`scripts/admin/`)
Server administration and moderation scripts.

### GUI (`scripts/gui/`)
User interface scripts and menu systems.

## 🎯 Naming Convention

Scripts follow a clear naming pattern:
- Lowercase with hyphens: `auto-farm.lua`
- Descriptive names: `infinite-jump.lua`, `speed-boost.lua`
- Always use `.lua` extension

## 💡 Best Practices

- ✅ Keep scripts focused on a single purpose
- ✅ Add clear comments and documentation
- ✅ Include script headers with metadata
- ✅ Test before committing
- ✅ Follow the directory structure
